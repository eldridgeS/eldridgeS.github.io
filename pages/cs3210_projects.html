Linux Completely Fair Scheduler (CFS) for xv6
This capstone project involved designing and implementing a robust, fair process scheduler inspired by the Linux kernel's Completely Fair Scheduler (CFS). The scheduler was integrated into the xv6 operating system, replacing its default round-robin scheduler with a weight-based, time-slicing approach.

Key Features & Implementation Details

  • Proportional Share Scheduling: Processes are scheduled based on their dynamically calculated virtual runtime (vruntime), ensuring CPU time is distributed fairly according to process weights.
  • Data Structures: Managed the run queue efficiently to keep track of process states and vruntime.
  • Kernel-Level Modifications: Adjusted core kernel structures, context switching, and timer interrupts to support accurate time accounting.
  • Performance Optimization: Reduced scheduling latency and improved responsiveness under heavy multiprogramming workloads.
Core Operating System Fundamentals
Early projects focused on building a strong foundation in OS concepts through direct interaction with the kernel.

System Calls and Process Management

  • System Call Implementation: Added custom system calls to the xv6 kernel to trace process behavior and retrieve system information.
  • Process Creation & Management: Gained deep understanding of `fork()`, `exec()`, `wait()`, and process state transitions.
  • User-Space Utilities: Developed user-space programs that interface with the newly created system calls to demonstrate functionality and reliability.
Memory Management and Synchronization
Explored the intricacies of modern memory architectures and concurrent programming.

Virtual Memory and Concurrency

  • Page Tables & Virtual Memory: Manipulated page directories and page tables to implement advanced memory management techniques such as lazy page allocation and copy-on-write (COW) fork.
  • Synchronization Primitives: Implemented and utilized spinlocks, mutexes, and condition variables to resolve race conditions and avoid deadlocks in multi-threaded environments.
  • Concurrency Control: Designed thread-safe data structures within the kernel to handle parallel execution across multiple CPU cores.
