High Performance Computer Architecture (ECE 4100) Projects

A comprehensive suite of projects focused on quantitative evaluation and simulation of high-performance processor architectures. These projects, developed in C++ for ECE 4100, analyze the performance impact of architectural decisions, ranging from basic pipelining and superscalar execution to advanced multi-core cache coherence protocols.
Directory-Based Cache Coherence Simulator
The most extensive project in the sequence involved building a cycle-accurate, trace-driven simulator to model multi-core cache coherence. The simulator accurately mimics the interactions between private L1 caches and a shared main memory directory.

Key Features & Implementation Details

  • Protocol Implementation: Implemented a full directory-based MESI (Modified, Exclusive, Shared, Invalid) coherence protocol.
  • Trace-Driven Simulation: Parsed and processed real-world memory access traces (read/write operations) across multiple simulated processor cores.
  • Interconnect Modeling: Modeled the latency and message passing between cache controllers and the central directory, accounting for invalidation traffic and write-backs.
  • Performance Metrics: Generated detailed statistics on cache hit/miss rates, memory traffic overhead, and overall system performance scalability.
Pipeline and Cache Performance Simulator
Designed a flexible simulator to evaluate the interaction between a processor pipeline and a hierarchical memory system.

Pipelining and Memory Hierarchy

  • Cache Configuration: Simulated configurable L1 and L2 caches (varying sizes, associativities, block sizes, and replacement policies such as LRU).
  • Pipeline Hazards: Modeled structural and data hazards, evaluating the performance impact of stalls and bypassing.
  • Quantitative Analysis: Extracted metrics like Average Memory Access Time (AMAT) and Instructions Per Cycle (IPC) to justify design tradeoffs.
Instruction-Level Parallelism (ILP) and Branch Prediction
Explored advanced superscalar processor techniques to maximize instruction throughput.

Out-of-Order Execution & Tomasulo's Algorithm

  • Dynamic Scheduling: Implemented a simulator modeling Tomasulo's algorithm with a Reorder Buffer (ROB) to support out-of-order execution and in-order commit.
  • Branch Prediction: Integrated dynamic branch prediction schemes (e.g., Gshare, 2-bit local predictors) and modeled the performance penalties associated with branch mispredictions and pipeline flushes.
  • Resource Allocation: Analyzed the performance limits imposed by available hardware resources (e.g., number of reservation stations, ALUs, and execution units).
