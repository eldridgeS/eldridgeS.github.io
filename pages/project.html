UVM Verification of a GCD Module
SystemVerilog UVM Testbench Development
Implemented a complete Universal Verification Methodology (UVM) testbench to verify a Greatest Common Divisor (GCD) RTL module. Architected a scalable verification environment with Driver, Monitor, Sequencer, Agent, Scoreboard, and Environment components using Transaction-Level Modeling (TLM). Developed a comprehensive sequence library with constrained random and directed test cases to stress the RTL. Achieved 98%+ code coverage with 100% FSM coverage through rigorous functional verification. Used Cadence Xcelium and SimVision for simulation and RTL debugging to identify and resolve bugs in the GCD logic.

Pipelined RISC-V Processor
SystemVerilog CPU Design (RV32I)
Implemented a 5-stage pipelined 32-bit RISC-V (RV32I) processor in SystemVerilog, implementing hazard detection, stall control, data forwarding, and branch flushing to minimize pipeline bubbles and maximize instruction throughput.

Debugged and optimized the design with ModelSim, Icarus Verilog, and GTKWave, building custom testbenches to ensure functional correctness, performance efficiency, and compliance with RV32I ISA specifications.

EtherCAT-Controlled 3D Laser Scanning for Lead Frame Inspection
Summer 2025 Internship Project
In summer 2025, I interned for a small semiconductor-automation company where I developed a 3D laser scanning system to automate the inspection of lead frames. This system precisely acquires high-resolution depth profiles of lead frames, which are critical components in semiconductor packaging. Accurate 3D scanning is vital for quality control, ensuring the integrity and precise dimensions of these components before further processing, thereby preventing defects in the final semiconductor devices. My work involved integrating EtherCAT-based motion-controlled high-speed camera acquisition, enabling synchronized data capture as the lead frame moved along a linear axis. The captured data is then processed into a 3D point cloud for detailed analysis and visualization.

VHDL FPGA LED Metronome on DE10-Standard
ECE2031 Digital Design Laboratory Group Project
My team designed a VHDL-based LED metronome peripheral for the DE10-Standard FPGA using Quartus Prime and ModelSim, implementing PWM-controlled LED brightness and clock division for adjustable BPM output. The system was structured around a modular SCOMP-based architecture to ensure accurate and scalable timing behavior. Control of tempo and LED states was enabled through SCOMP assembly, interfacing directly with memory-mapped FPGA registers. Simulation, waveform analysis, and timing closure verification were performed to ensure correct functionality and robust hardware-software integration across the entire design pipeline.
