Formal Verification of the Rx DSP
Contact Me
During my Summer 2026 internship at Astera Labs, I architected and deployed a complete Formal Verification (VC-Formal) framework from scratch for the digital Receiver DSP (EIC). Because the DSP implements complex fixed-point algorithms (like LMS adaptation and channel impulse estimation) with deep state machines, traditional simulation could not exhaustively cover all corner cases. This framework provided the exhaustive mathematical proof needed to catch elusive bugs before silicon fabrication.

The Challenge & The Framework
When I joined, zero formal infrastructure existed for the Rx DSP. My goal was to build a system that was robust, modular, and easy for the team to expand. I developed over 2,000 lines of SystemVerilog Assertions (SVA) covering four critical blocks: FFE LMS, Impulse Estimator, Clock and Reset, and Core Integrator.

Framework Architecture

  • Built to Scale: A modular directory structure where each block is self-contained with its own SVA file, TCL script, and run scripts.
  • Automation: Implemented run_all.sh for parallel regression across any block and formal app (FPV, FXP, CC, DPV, AEP).
  • Reporting: Developed formal_report.py, a Python script that generates a self-contained HTML dashboard summarizing pass/fail metrics across all properties.
  • Nightly Cron Regression: Automated the formal runs with timestamped results, surfacing regressions by morning.
Case Study: Bug #25 (FFE LMS)
Formal verification shines in finding deep corner cases. One of the most significant finds was "Bug #25" in the FFE LMS block.

The Symptom: An APB load to a given slice/tap wrote back the wrong value; the loaded tap did not hold what firmware wrote.
The Root Cause: The load was a read-modify-write operation. While the write destination was correctly addressed, the source it read was erroneously picked by a round-robin counter rather than the addressed slice.
The Discovery: I wrote targeted FPV assertions (fpv_bug_25) to check each slice/tap load-back independently. Formal verification returned a counterexample proving that the loaded tap took a value derived from the counter slice. I raised this to the designer, it was fixed, and re-verified clean.

Impact

  • Caught 8 RTL and specification issues before simulations were even running.
  • Uncovered critical issues like signed indexing into unsigned arrays, swapped accumulation datapaths, and missing soft reset synchronizers.
  • Built infrastructure designed to outlive the internship, establishing a new verification standard for the team.
